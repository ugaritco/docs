# Ugarit Documentation

You can find the online version of the Ugarit documentation at [https://ugarit.com/docs](https://ugarit.com/docs)

## Contribution Guidelines

If you are submitting documentation for the **current stable release**, submit it to the corresponding branch. For example, documentation for Ugarit 12 would be submitted to the `12.x` branch. Documentation intended for the next release of Ugarit should be submitted to the `master` branch.
